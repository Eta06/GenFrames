# Experiment records

Each completed experiment gets a Markdown record containing:

- hypothesis and reason for the experiment;
- Git commit and configuration;
- data manifest and split;
- hardware, software, precision, and seed;
- parameter count, latency, peak memory, and quality metrics;
- qualitative failure cases;
- decision: continue, revise, or eliminate.

Human A/B evaluations are recorded without revealing model identity until the
choice has been submitted.
