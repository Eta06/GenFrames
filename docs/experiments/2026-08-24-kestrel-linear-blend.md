# Kestrel: analytic linear-blend lower bound

Decision: continue as a fixed lower bound

## Purpose

Establish a learning-free score that the first trainable GenFrames candidate must
beat. Linear blending is especially misleading around moving object boundaries,
so it also gives a simple ghosting reference for future qualitative grids.

## Reproduction

- Git commit: `40f799e`
- Model: `genframes.models.LinearBlend`
- Dataset: `AnalyticMotionDataset`
- Samples: 256
- Resolution: 64x64
- Dataset seed: 1701
- Arbitrary target times: `{0.125, 0.25, 0.375, 0.5, 0.625, 0.75, 0.875}`
- Batch size: 16
- Device: NVIDIA GeForce RTX 3070
- Precision: FP32
- Clamp prediction to `[0, 1]`: yes

## Result

| Parameters | RGB MAE | RGB PSNR |
|---:|---:|---:|
| 0 | 0.0174143 | 26.2322 dB |

Runtime is not reported in this experiment because the latency harness has not
yet been committed. Quality values are generated by the common evaluation runner.

## Interpretation

The average score is high because most background pixels are static. Region and
motion-stratified metrics are required before claiming meaningful progress. The
minimal model must beat this baseline overall and on moving/occlusion pixels; an
overall-only gain can otherwise be obtained by learning background identity.
