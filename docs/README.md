# GenFrames documentation

- `research/`: paper and implementation surveys with explicit project roles.
- `data/`: dataset facts, provenance, licensing notes, and synthetic-data plans.
- `decisions/`: architecture decision records (ADRs).
- `experiments/`: immutable summaries of completed experiments and ablations.

Claims that affect implementation should cite a primary paper, official project
page, official repository, or dataset owner. Unknown licensing or reproducibility
details are recorded as unknown rather than guessed.
